# Weekly Promotion

Use this checklist when the user wants to convert learning-log entries into a dedicated reusable skill.

## Promotion Criteria

- promote only items that repeated more than once or are clearly durable rules
- merge duplicate entries into one normalized instruction
- keep project-specific incidents out of the permanent skill unless they represent a stable repository rule
- rewrite raw feedback into imperative instructions for another agent instance

## Promotion Workflow

1. Read `references/learning-log.md`.
2. Group entries by theme, such as coding style, task execution, communication, or repository workflow.
3. Drop stale, contradictory, or one-off notes.
4. Convert stable groups into concise skill instructions.
5. Create or update the target skill.
6. Mark promoted source entries with `Status: promoted` and add the destination skill name.

## Suggested Themes

- communication preferences
- code editing rules
- repository workflow constraints
- testing and verification expectations
- framework-specific conventions
